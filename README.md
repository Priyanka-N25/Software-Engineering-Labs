# Software Engineering Labs

This repository contains my Software Engineering laboratory submissions for Labs 01–05. Each lab focuses on a different aspect of software engineering, including requirements engineering, Agile project management, software architecture, AI-assisted development, and static code analysis.

## Lab Index

### Lab 1: Requirements Engineering & UML Use-Case Modelling

**Problem Statement:** Telemedicine Slot Booking & Prescription Portal

**Objective:** Elicit key functions and constraints from the given scenario, document functional and non-functional requirements, and translate them into a UML use-case diagram and use-case flow.

**Deliverables:**
- Requirements table
- UML use-case diagram
- Use-case flow specifications

### Lab 2: Agile Backlog Creation & Sprint Simulation in Jira

**Problem Statement:** Telemedicine Slot Booking & Prescription Portal

**Objective:** Use Jira to turn functional requirements into Agile backlog items, simulate a sprint, and analyse project progress.

**Deliverables:**
- Product backlog with epics and user stories
- Story-point estimation
- Sprint board
- Burndown chart
- Reflection questions and answers

### Lab 3: Component Modelling & Architectural Pattern Selection

**Problem Statement:** Telemedicine Slot Booking & Prescription Portal

**Selected Architecture:** Microservices Architecture

**Objective:** Evaluate architectural styles, select an appropriate architecture for the assigned scenario, and create a UML component diagram showing modules, interfaces, and dependencies.

**Deliverables:**
- Architecture selection and justification
- Component diagram

### Lab 4: Vibe Coding

**Assigned Project:** Maze Chase

**Original Repository:** [11_maze_chase](https://github.com/SETAPESU26/11_maze_chase)

**Objective:** Use AI-assisted coding tools to fix broken code, implement required features, test the updated Python game, and push the modified project to a personal GitHub repository.

**Work Completed:**
- Reviewed and ran the assigned project.
- Recorded gameplay before modifications.
- Used AI-assisted prompts to fix broken code and implement the required features.
- Tested the updated game and recorded gameplay after modifications.
- Pushed the updated code to a personal repository.

**Deliverables:**
- Before and after gameplay videos
- Updated source code
- Exported AI chat history in PDF or document format

### Lab 5: Static Code Analysis

**Project:** Scholarship Screener

**Original Repository:** [L5_11_scholarship_screener](https://github.com/SETAPESU26/L5_11_scholarship_screener)

**Objective:** Analyze and improve source code using static analysis tools to identify potential code quality, style, and security issues.

**Tools and Results:**

| Tool | Final Result |
|---|---|
| Pylint | 10.00/10 |
| Flake8 | No reported errors |
| Bandit | No issues identified |

**Deliverables:**
- Updated Python source code
- Pylint report
- Flake8 report
- Bandit report
- Issues and reflections documentation, where required
- Static analysis results PDF
