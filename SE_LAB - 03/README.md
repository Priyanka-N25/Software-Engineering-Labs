# Lab 3: Component Modelling & Architectural Pattern Selection

## Problem Statement: Telemedicine Slot Booking & Prescription Portal

### Objective

Evaluate different architectural styles, select the most appropriate one for the assigned scenario, and create a comprehensive UML Component Diagram showing modules, interfaces, and dependencies. This lab focuses on understanding how components interact within a system and how architectural decisions impact system design.

###Selected Architecture

Microservices Architecture

### Deliverables

- Architecture selection and justification
- Component diagram

### Outcome

To Evaluate architectural styles, Select appropriate architecture, Design component diagrams and Document architectural decisions.
