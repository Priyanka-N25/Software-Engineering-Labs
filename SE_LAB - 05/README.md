# Lab 5: Static Code Analysis

## Project

**Scholarship Screener**

**Repository:** [L5_11_scholarship_screener](https://github.com/SETAPESU26/L5_11_scholarship_screener)

## Objective

To analyze the source code using static analysis tools to identify potential code quality, style, and security issues, and improve the code based on the findings.

## Tools Used

- **Pylint:** Code quality and error analysis
- **Flake8:** Code style and formatting checks
- **Bandit:** Security issue detection in Python code

## Work Completed

- Reviewed the Scholarship Screener source code.
- Ran Pylint to evaluate code quality and identify potential issues.
- Ran Flake8 to check code style and formatting.
- Ran Bandit to identify potential security issues.
- Improved the code based on static analysis findings.
- Regenerated the analysis reports after making improvements.

## Final Results

| Tool | Result |
|---|---|
| Pylint | 10.00/10 |
| Flake8 | No reported errors |
| Bandit | No issues identified |

## Deliverables

- Updated Python source code (`scholarship_system.py`)
- Pylint report (`pylint_report.txt`)
- Flake8 report (`flake8_report.txt`)
- Bandit report (`bandit_report.txt`)
- Issues and reflections documentation, where required
- Static analysis results PDF submitted for the lab

## Outcome

The project was improved through static code analysis, resulting in a Pylint score of 10.00/10, no reported Flake8 errors, and no issues identified by Bandit in the analyzed file. This lab provided practical experience in code quality assessment, coding standards, and basic security analysis.
