# Lab 2: Agile Backlog Creation & Sprint Simulation in Jira

## Problem Statement

**Telemedicine Slot Booking & Prescription Portal.**

### Objective

Use Jira to turn functional requirements into Agile backlog items, simulate a sprint, and analyse progress.

### Deliverables

- Product backlog with epics and user stories
- Story-point estimation
- Sprint board
- Burndown chart
- Reflection questions and answers

### Outcome

The project work is structured into manageable tasks and planned sprints, supporting progress tracking and Agile project management.
