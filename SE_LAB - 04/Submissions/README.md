# Lab 4: Vibe Coding

## Objective

To use Vibe Coding tools to fix broken code and add the required features to an existing project. The lab focuses on writing effective prompts to complete the task within three to four attempts, testing the application, and pushing the updated code to a personal GitHub repository.

## Assigned Project

**Project:** Maze Chase

**Repository:** [11_maze_chase](https://github.com/SETAPESU26/11_maze_chase)

## Tools Used

- Python
- Git and GitHub
- Vibe Coding tool (AI-assisted coding)

## Work Completed

- Reviewed the assigned repository and its README to understand the requirements.
- Cloned the assigned project and ran the Python-based game.
- Recorded a 10-second video of the game before making changes.
- Used AI-assisted prompting to identify and fix broken code.
- Implemented the required features described in the project's README.
- Tested the updated game after making the changes.
- Recorded a 10-second video of the game after completing the changes.
- Pushed the updated code to my personal GitHub repository.

## Deliverables

The following deliverables are included in the Lab 4 submission folder:

1. **Before video:** A 10-second recording of the original game before modifications.
2. **After video:** A 10-second recording of the updated game after modifications.
3. **Updated source code:** The corrected code with the required features implemented.
4. **AI chat history:** Exported conversation history documenting the prompts and AI-assisted development process, submitted as a PDF or document.

## Outcome

The lab provided practical experience in AI-assisted software development, prompt engineering, debugging, feature implementation, testing, and Git-based version control.
